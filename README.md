# RoadGuard AI (traffcam)

เว็บแอปกล้องสำหรับ iPhone/iPad ที่ใช้ Ultralytics YOLO26 ตรวจจับวัตถุแบบเรียลไทม์และแจ้งเตือนความเสี่ยงระหว่างเดิน ขี่จักรยาน/มอเตอร์ไซค์ และขับรถ

## ความสามารถ

- ใช้กล้องหลังและประมวลผล YOLO ในเบราว์เซอร์ด้วย WebGPU หรือ CPU/Wasm fallback
- อ่านความเร็วจาก GPS (เมตร/วินาทีตามมาตรฐานเว็บ) และแสดงเป็น กม./ชม.
- ปรับระยะเตือนตามความเร็วและระยะหยุดโดยประมาณ พร้อมลดการเตือนเมื่อรถหยุด
- แสดงกรอบวัตถุ ชื่อภาษาไทย ระยะโดยประมาณ และแนวการเคลื่อนที่
- ตรวจคู่เส้นเลนจากภาพถนนจริงและวาดตามแนวที่พบเท่านั้น หากความมั่นใจไม่พอจะไม่แสดงเส้นเลน
- ตรวจขอบคอนโซล/ตัวรถด้านล่างและตัดพื้นที่นั้นออกจาก YOLO เพื่อลดการตรวจวัตถุผิด
- ใช้เลนที่ตรวจพบประเมินพื้นที่แนวทาง เวลาปะทะโดยประมาณ (TTC) และระดับเฝ้าระวัง/อันตราย
- ยืนยันความเสี่ยงต่อเนื่องหลายเฟรมก่อนเตือน เพื่อลดการเตือนหลอกและการเตือนซ้ำ
- เตือนบนจอด้วยเสียงบี๊บ เสียงพูดภาษาไทย และการสั่นเมื่ออุปกรณ์รองรับ
- มี 3 โหมด: เดิน, ขี่ และขับรถ
- ปรับสัดส่วนกล้องและพิกัด overlay อัตโนมัติเมื่อหมุน iPhone/iPad ระหว่างแนวตั้งและแนวนอน

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` หรือ deploy บน HTTPS เพื่อให้เบราว์เซอร์อนุญาตการใช้งานกล้องและตำแหน่ง

ระหว่าง `npm run build` ระบบจะดาวน์โหลด `yolo26n.onnx` จาก release ทางการของ Ultralytics ตรวจสอบขนาดและ SHA-256 แล้วนำไปเสิร์ฟเป็น static asset แบบ same-origin โมเดลไม่ได้ถูก commit เข้า repository

## ตรวจสอบและ build

```bash
npm run lint
npm run typecheck
npm run build
```

## ข้อควรระวัง

แอปนี้เป็นผู้ช่วยทดลอง ไม่ใช่ระบบ ADAS หรืออุปกรณ์ความปลอดภัยที่ผ่านการรับรอง ระยะและ TTC เป็นค่าประมาณจากกล้องตัวเดียว อาจตรวจพลาด แจ้งเตือนช้า หรือไม่ทำงานในสภาพแสง/อากาศบางแบบ ห้ามถือหรือปรับมือถือระหว่างขับรถ และต้องยึดอุปกรณ์ให้มั่นคงโดยไม่บดบังทัศนวิสัย
