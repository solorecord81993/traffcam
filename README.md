# RoadGuard AI (traffcam)

เว็บแอปกล้องสำหรับ iPhone/iPad ที่ตรวจสิ่งกีดขวางแบบเรียลไทม์และแจ้งเตือนความเสี่ยงระหว่างเดิน ขี่จักรยาน/มอเตอร์ไซค์ และขับรถ

## ความสามารถ

- หน้าแรกเลือกใช้เครื่องเป็น Camera หรือ Monitor ภายในเว็บเดียวกัน
- สร้างรหัสห้องสุ่ม 6 ตัว เชื่อมภาพสด ผลตรวจจับ สถานะ GPS และเส้นเลนผ่าน WebRTC P2P โดยรองรับ Monitor หลายเครื่อง
- เครื่อง Monitor ปรับโหมดเดินทาง, เป้าหมาย 30/45/60 FPS และเสียงเตือนของเครื่องกล้องได้แบบเรียลไทม์
- ใช้ ONNX Runtime Web ใน Web Worker เลือก WebGPU เมื่อพร้อม และ fallback เป็น WASM/SIMD
- วิเคราะห์แบบ obstacle-only ไม่ต้องระบุชื่อสิ่งของ เพื่อลดงาน post-processing และลดความหน่วง
- วาดภาพกล้องและไฮไลต์แยกจาก AI loop พร้อมตั้งค่าเป้าหมาย 30, 45 หรือ 60 FPS และ tracking ระหว่างผลตรวจแต่ละรอบ
- อ่านความเร็วจาก GPS (เมตร/วินาทีตามมาตรฐานเว็บ) และแสดงเป็น กม./ชม.
- ใช้ความเร็ว GPS เป็นข้อมูลประกอบการประเมินการเคลื่อนที่ พร้อมลดการเตือนเมื่อรถหยุด
- แสดงกรอบไฮไลต์ “สิ่งกีดขวาง” สีแดงเมื่ออยู่ใกล้ และสีเหลืองเมื่อมีแนวโน้มเข้ามาใกล้
- ตรวจคู่เส้นเลนจากภาพถนนจริง ติดตามขอบเลนเป็นช่วงจากใกล้ไปไกล และวาดตามเส้นโค้ง/เส้นเบี้ยวที่พบแทนการบังคับเป็นเส้นตรง หากความมั่นใจไม่พอจะไม่แสดงเส้นเลน
- ตรวจขอบคอนโซล/ตัวรถด้านล่างและตัดพื้นที่นั้นออกจากโมเดล เพื่อลดการตรวจวัตถุผิด
- ใช้เลนที่ตรวจพบประเมินพื้นที่แนวทางและระดับเฝ้าระวัง/อันตราย
- ยืนยันความเสี่ยงต่อเนื่องหลายเฟรมก่อนเตือน เพื่อลดการเตือนหลอกและการเตือนซ้ำ
- เตือนบนจอด้วยเสียงบี๊บ เสียงพูดภาษาไทย และการสั่นเมื่ออุปกรณ์รองรับ
- มี 3 โหมด: เดิน, ขี่ และขับรถ
- ปรับสัดส่วนกล้องและพิกัด overlay อัตโนมัติเมื่อหมุน iPhone/iPad ระหว่างแนวตั้งและแนวนอน
- แสดง FPS แยกเป็นอัตราภาพกล้อง อัตราวาดจอ และอัตราอนุมาน AI เพื่อบอกสมรรถนะจริงของอุปกรณ์

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` หรือ deploy บน HTTPS เพื่อให้เบราว์เซอร์อนุญาตการใช้งานกล้องและตำแหน่ง

ระหว่าง `npm run build` ระบบจะดาวน์โหลด `yolo26n.onnx` จาก release ทางการ ตรวจสอบขนาดและ SHA-256 แล้วนำไปเสิร์ฟเป็น static asset แบบ same-origin พร้อมคัดลอก WASM runtime ของ ONNX Runtime ไปที่ `public/ort/` โมเดลและ runtime ไม่ได้ถูก commit เข้า repository

## ตรวจสอบและ build

```bash
npm run lint
npm run typecheck
npm run build
```

## ข้อควรระวัง

แอปนี้เป็นผู้ช่วยทดลอง ไม่ใช่ระบบ ADAS หรืออุปกรณ์ความปลอดภัยที่ผ่านการรับรอง การประเมินความใกล้และทิศทางเป็นค่าประมาณจากกล้องตัวเดียว อาจตรวจพลาด แจ้งเตือนช้า หรือไม่ทำงานในสภาพแสง/อากาศบางแบบ ห้ามถือหรือปรับมือถือระหว่างขับรถ และต้องยึดอุปกรณ์ให้มั่นคงโดยไม่บดบังทัศนวิสัย

## เทคโนโลยีและสิทธิ์ใช้งาน

- Next.js 16, React 19 และ TypeScript
- [`peerjs`](https://www.npmjs.com/package/peerjs) สำหรับ WebRTC P2P และการจับคู่ด้วยรหัสห้อง
- [`onnxruntime-web`](https://www.npmjs.com/package/onnxruntime-web) และโมเดล ONNX สำหรับตรวจสิ่งกีดขวาง

โมเดลที่ดาวน์โหลดมาจาก release ภายนอกควรตรวจสอบเงื่อนไขใบอนุญาตของโมเดลก่อนนำไปใช้เชิงพาณิชย์หรือเผยแพร่เป็นผลิตภัณฑ์
